# Mini Militia 3D — Native Android COD-Style FPS

A native **Kotlin + OpenGL ES 3.0** landscape 3D first-person shooter inspired by *The Rise of NOOBIE (Outpost)*, built with zero engine bloat for fast performance on Android 8.0 (Oreo) and above.

## Features
- **COD-Style 3D First-Person Gameplay:** Full 360° touch-drag camera look, left virtual thumbstick movement, ADS iron-sight zoom, dynamic crosshair + hitmarkers, and tactical radar minimap.
- **Full 3D Physics:** Gravity, rechargeable jetpack thrusters, jumping across 3D floating Outpost islands and sky-bridges, weapon recoil, bouncing 3D frag grenades, and RPG blast knockback.
- **11 Custom 3D Models:** Noobie FPS viewmodels (Uzi SMG, Chrome Magnum, Pump Shotgun, RPG-7), 3D Sarge & Enemy Soldier AI bots, Frag Grenade, Outpost Floating Islands, Tropical Monstera Bushes, and 3D Explosion meshes.
- **Built-in Force Update Checker:** Automatically checks GitHub Releases and displays a "What's new" changelog card when a newer APK is available.
