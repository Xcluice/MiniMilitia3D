# MiniMilitia3D — Outpost Arena

A browser-based **3D Mini Militia** action game built with **HTML5, JavaScript, and Three.js**, featuring all 11 stylized 3D models inspired by *The Rise of NOOBIE (Outpost)*.

## Features
- **Full 3D Physics:** Gravity, rechargeable jetpack thrusters, floating Outpost cliff collisions, weapon recoil, bouncing frag grenades, and radial RPG/grenade blast knockback.
- **11 Custom 3D Models (`models3d.js`):** Noobie, Sarge, Enemy Soldier, Chrome Magnum Revolver, Uzi SMG, Pump Shotgun, RPG-7 Launcher, Frag Grenade, Outpost Floating Island, Tropical Monstera Bush, and Stylized Explosion Mesh.
- **Mobile & Desktop Ready:** Dual virtual touch joysticks on Android/iOS; `WASD` / Arrows + Mouse + `1-4` + `G` on desktop.
- **Instant Run:** Zero build tools or heavy downloads — open `index.html` or deploy directly to GitHub Pages / Vercel / Netlify.

## Controls
| Action | Desktop | Mobile |
| :--- | :--- | :--- |
| Move | `A` / `D` or Arrow Keys | Left Joystick |
| Jetpack | `W` / `Space` / Up Arrow | Push Left Joystick Up |
| Aim & Fire | Mouse + Left Click | Right Joystick (auto-fire) |
| Switch Weapon | `1`–`4` or Mouse Wheel | Bottom Weapon Dock |
| Throw Frag | `G` or Right Click | `FRAG` Button |
| Reload | `R` | `RELOAD` Button |
